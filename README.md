# Next.js

Пример приложения [Next.js](https://nextjs.org/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/out` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. В `next.config.mjs` включён
статический экспорт (`output: 'export'`): `npm run build` собирает отдельную HTML-страницу на
каждый адрес и кладёт их в `out`, поэтому SPA не нужен — несуществующий адрес отвечает 404.

В демо нет `package-lock.json`: версии пакетов выбираются при сборке по диапазонам из
`package.json`.

Пример с серверным рендерингом — `app-example-next-ssr`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме с отслеживанием изменений
npm run dev

# сборка для продакшн с минификацией
npm run build
```

Нужен Node.js 20.9 или новее.
